New
- Configure per-agent user Skills and Rules directories for ACP agents, then preview and confirm copies on this machine or a selected SSH host. Skills include complete resources; rules are copied unchanged, without prompt injection.
- Add Gitea to Git Accounts with personal access token sign-in, HTTP or HTTPS instances, custom Web ports, saved sign-in and sign-out.
- Connect Gitea to core Stash workflows: import and sync issues, filter all or personal issues, publish, edit, comment, close, and follow pull request states, merges and available checks or reviews.

Improved
- Track customization copies for incremental updates, protect existing and externally modified files, retain stale copies after source removal, and check overlapping directories and symbolic links.
- Isolate Gitea accounts and credentials by protocol, host and port, preserve HTTP links, and resolve unambiguous SSH remotes to configured Web instances.
- Require confirmation before HTTP sign-in because tokens and content travel unencrypted; forge API requests do not follow redirects to unintended destinations.
- Gitea local image upload is not supported yet. Publishing local images is explicitly blocked with an explanation; remote image links remain unchanged.

Fixed
- Preserve existing ACP arguments containing spaces when saving directory or other settings without editing the arguments.
- Treat unavailable or inaccessible pull request checks and reviews as unknown instead of reporting success.
- Report non-JSON forge responses as recoverable errors while preserving local Stash data.
