New
- Preview PDF files directly in the editor and chat side panel, with page navigation and zoom controls.
- Preview Word (.docx) documents with a lightweight native renderer, without installing Office or LibreOffice.
- Preview Excel (.xlsx) workbooks as read-only tables, with worksheet switching and horizontal/vertical scrolling.
- Compile local LaTeX source into a PDF preview using the bundled offline Tectonic engine, common packages and Chinese fonts. The preview uses unsaved editor content and preserves relative file references.

Fixed
- Scrolling Word documents no longer unexpectedly zooms at the top or bottom; trackpad pinch zoom remains available.
- Reloaded PDFs and recompiled LaTeX previews show the new output instead of a cached document.
- PDF and Office files no longer pass through the text editor's UTF-8 reading or save paths.

Notes
- Legacy .doc/.xls files must be saved as .docx/.xlsx. Advanced Office layout, Excel charts and formula recalculation are not supported.
- LaTeX compilation is local only and uses a curated offline package set, not a full TeX Live installation. Missing packages produce a local error; no runtime downloads are performed. Compile only trusted LaTeX documents.
