新功能
- Stash 可与 GitHub / GitLab 的 issue 双向同步，展示评论、状态和关联 PR 动态，支持确认后发布及合并议题。
- Stash、Markdown 预览和对话输入框采用新的 Markdown 编辑器，支持表格单元格编辑、链接操作和 front matter 属性编辑。
- SSH 网络中断后可重新接回原会话，保留远程终端、智能体和语言服务器，并补齐断线期间的输出。
- 模型支持跨上游的角色配置、独立接口、一键复制及移除已下架模型；对话缩略图新增用户消息定位与预览。

改进
- 减少长对话、语法高亮、图片和排版缓存的内存占用，改善流式输出和快速滚动；Windows 改用 Skia 绘制。
- 输入框支持打开文件及文件夹标签、查看命令详情，并在智能体工作时快速发送排队消息。
- 保留本地 ACP 模型、模式和思考等级选择、共享及无窗口 MCP、修改审阅、SSH 保存配置和 GitHub 更新渠道。

修复
- 修复 Markdown 图片加载导致滚动位置跳动、表格链接操作及部分 Windows 输入问题。
- 修复 Claude Code 思考等级受环境变量锁定、会话重命名不同步和计划模式提示词缓存问题。
- 修复工具栏缓存导致仅提供思考等级的 ACP 智能体选择器未及时刷新的问题。
