本次将本地模型网关调用纳入用量统计，经过网关的 ACP agent 和其他客户端可与 Claude Code 一起查看。

新功能
- 统计 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 的网关调用，支持流式请求和跨协议转换。
- 记录上游、模型、接口返回的 token、缓存与推理用量、估算费用、耗时、错误和取消情况；跨协议请求只计一次。
- 通过 x-baocode-agent 请求头或可识别的 agent User-Agent 区分客户端，并在用量页面按 agent 筛选。会话和子 agent 请求头可保留更细的归属信息。

改进
- 调用详情和导出的用量记录显示网关来源与客户端名称，并兼容旧用量记录。
- 为 OpenAI Chat Completions 流式请求启用用量返回，支持跨数据块解析；未返回的 token 数不作估算。
