BaoCode 2.0.10 improves desktop input recovery and the SSH agent experience.

Fixed
- Recover sidebar resizing when a mouse release is lost: moving or clicking again restores interaction instead of leaving an invisible layer blocking the chat list.
- Retry a temporary file snapshot error once before an SSH conversation turn, reducing missed file changes made by an agent.

Improved
- Show actual upload progress while installing ACP agents over SSH, with progress tracked separately for each host.
