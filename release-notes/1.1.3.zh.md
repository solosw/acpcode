新功能
- 侧边栏支持多选对话，可批量置顶、取消置顶、归档、恢复和删除；支持修饰键选择、范围选择和成组拖动排序。
- Responses 和 Codex 提供商新增 Fast 模式，可默认请求 priority 服务等级；需要模型和上游支持，价格可能不同。
- Markdown 预览中的图片可点击打开大图。

修复
- 侧边栏的选中样式与资源管理器保持一致，修复在对话列表和项目标题上使用触控板时无法正常滚动的问题。
- 鼠标悬停在提示浮层上时，仍可滚动下方内容。
- 调整 Markdown 标题分隔线，使其更柔和并与主题分隔线颜色一致。
- 修复 Stash 面板侧边栏开关与 macOS 窗口控制按钮重叠的问题。
- 移除子智能体标题中多余的展开箭头。
