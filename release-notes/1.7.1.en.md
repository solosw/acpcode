Scheduled tasks and sleep prevention

New
- Scheduled Tasks sits directly below Stash. Choose Claude Code or a configured ACP agent, using the conversation's live model, mode, approval and reasoning options.
- Schedule prompts by day and local time, target local or SSH projects, use existing or new Git working trees, and create or reuse ordinary conversations without switching the focused chat.
- Run tasks immediately, pause, edit or delete them, inspect errors and open their conversations. Keep the app running; missed occurrences are skipped and busy conversations are not interrupted.
- Settings → General now has Prevent computer sleep. The saved choice keeps this computer awake while the app runs, including in the background, without forcing the display to stay on or changing system power settings.

Fixed
- ACP prompts wait for pending configuration acknowledgments, including legacy mode changes, so a prompt cannot overtake the selected settings.

The upstream 1.7.1 notes below are retained for reference; those upstream changes were already included in this fork's 1.7.0 merge.

This release helps us track down the app becoming unresponsive while an agent works: on macOS, a hang is now written down as it happens, and sent with the diagnostics. It also fixes the chat's terminal and split panes.

Diagnostics
- On macOS, when the interface stops responding for 4 seconds, what each thread was doing and how long it lasted go into the logs, and are sent with the diagnostics. It costs next to nothing until then, and samples at most 3 times a run.
- The logs say how each run ended (quit, update, ended by the system, crashed); a run that ended without a word is noted as the next one starts.
- The diagnostics include the reports the system kept of the app: macOS' crashes, hangs it was force quit at, and long stretches of high CPU, and Windows Error Reporting's. The computer's name is left out of their names.

Fixed
- The chat's terminal is each conversation's own: each split pane shows its project's terminals, as wide as the conversation. A pane's title bar buttons for the terminal, the side panel and the editor act on that pane's agent.
- Dragging a line to resize a terminal tells it the size once you stop, rather than filling the scrollback with the prompt redrawn at every width.
- Opening a remote project or file, a folder that is slow to read shows "Reading…" rather than the pick going away.
- Source control: Generate Commit Message sits beside the commit buttons; the divider above the message stays under the pointer as you drag it, and a double click resets it.
