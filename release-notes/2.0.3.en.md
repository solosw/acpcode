This release adds ACP system prompt customization and Skills support, wired to BaoCode's Built-in Core prompt and Skills while staying compatible with ACP v1 agents.

New
- Negotiate ACP `systemPrompt` (`append` and `mode.override`) on `session/new` and `session/load`, forwarding Settings → Built-in Core system prompt settings and workspace/bot instructions with clear warnings when an agent does not support them.
- Support ACP v2 structured `skill` commands and `skill` prompt blocks (including inline references when advertised), falling back to plain text automatically on ACP v1 agents.
- Load enabled BaoCode Skills from `~/.claude/skills` and `<project>/.claude/skills` on both local and SSH hosts, respecting Settings → Customize switches, injecting a model-invocable skills catalog into `systemPrompt`, expanding `/skill-name` invocations for v1 and v2 agents, and opening `SKILL.md` from command tags.
