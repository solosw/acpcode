More reliable browser tool connections

Improved
- Local ACP agents that support HTTP now share the app's in-process MCP service instead of starting a separate BaoCode proxy for each conversation. Each conversation keeps its own project context and credentials, with independent cancellation.
- User-level MCP registration still supports external clients and stdio-only agents. Custom same-name servers, project overrides, disabled entries and remote SSH configuration remain unchanged.

Fixed
- On macOS, the MCP stdio proxy no longer creates an application window or takes focus.
- Closing a conversation, stopping an agent or restarting it releases shared MCP connections, revokes temporary credentials and cancels unfinished calls.
