这一版同步了上游 2.0.0 系列更新，新增 Windows BaoCode Bash、对话协作、项目附加文件夹和设置迁移，并改进 SSH 终端、文件传输与对话用量统计。

新功能
- Windows 可以选择 BaoCode Bash，内置常用命令，无需安装 Git；设置 → 通用 → 命令行中可选择，也保留 Git Bash、cmd、PowerShell 和自定义程序。
- 设置 → 通用中开启「Agent 可以统筹其他对话」后，一个对话可以给其他对话分配任务、查看进度并等待结果。
- 项目可以添加其他文件夹，Agent、文件树、终端和 @ 提及都能使用这些目录。
- 设置 → 数据目录支持导出设置、上游、模型和快捷键，在另一台电脑上导入；API key 只有勾选时才导出。
- 编辑并重发之前的消息时，可以选择撤回 Agent 从那条消息起做的文件修改，保留你或其他对话后来的改动。支持 Claude Code 和 BaoCode Agent，不包含命令造成的修改。
- SSH 终端支持用 code 打开远程文件和文件夹；上传、下载显示进度并支持取消，远程文件浏览器可下载文件夹。
- 自定义中增加项目记忆管理，Git 账号增加 GitCode 支持，Markdown 和计划预览支持查找。
- Claude Code 模型设置可查看并使用订阅的额度重置；一条消息最多可附带 100 张图片。

改进
- 远程终端大量输出时，不再拖慢同一 SSH 连接上的文件与 Agent 请求；列出大体积会话时降低内存占用。
- 会话在外部终端继续后，回到 BaoCode 会自动重新读取。
- 第三方模型使用上游报告的上下文长度，上下文统计与最终请求用量对齐。
- Workflow 显示子 Agent 卡片与进度，归档对话按文件夹分组。
- Linux .deb 支持 glibc 2.31 系统，包括银河麒麟 V10 SP1 和统信 UOS 20。
- 搭配手机版 0.2.0，可发送文件给 Agent、接收 iPhone 推送，并更快地重新打开对话。

修复
- 修正大量截图、工具结果和中断流式输出时的上下文统计，以及上游输入 token 为 0 时的缓存命中显示。
- 修正第三方模型在计划模式、完全访问权限下的命令与子 Agent 权限判断，以及部分 Responses 上游发送图片时报 400 的问题。
- 修正 macOS 外接显示器睡眠后的窗口位置、辅助功能引起的闪退，以及 Windows 中文输入和代理变量兼容问题。
- 改进对话文字选择、微信语音输入、Markdown 公式和符号链接技能加载。
- 修正远程文件链接、SSH 文件浏览界面和提交面板交互问题。
