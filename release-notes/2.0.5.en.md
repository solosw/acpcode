This release reworks ACP agent settings around servers and makes registry agents ready on every connected host.

Changed
- Configure each ACP agent per SSH server. The "This machine" option and the skills folder setting are gone; command, arguments, environment and rules folder are saved for each server.
- Installing an agent from the ACP Registry downloads its builds for every published platform. When BaoCode connects to a server, it checks for the matching build and copies it over if it is missing.
- Add your own agents by entering registry JSON: a single agent entry, a list of entries, or a full registry document. Entries are checked and previewed before they are saved.
