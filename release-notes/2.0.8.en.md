BaoCode can now discover existing ACP conversations and reopen them in the right project.

New
- Find past conversations from compatible ACP agents on this computer and connected SSH projects, then open them to load their history.

Improved
- Download ACP packages locally and transfer missing builds or package caches to SSH servers. npm and uv agents use the transferred cache offline.
- Update a custom ACP agent by editing its saved registry JSON. For an official agent with no newer version, you can download the current version again.
