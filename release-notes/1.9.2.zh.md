新功能
- SSH 远程支持 RISC-V 架构的 Linux 主机。
- 装了 magpie 时，设置 → 模型里可以一键「连接 magpie」，上游跟着 magpie 的本地网关走，不用手填。
- 活动栏里的改动文件列表可以拖动边缘调高。

修复
- 带 ANSI 颜色码的日志能当文本打开，不再被认成二进制文件。
- 通过 OpenCode 使用 DeepSeek 时，新对话不再报 400 错误。
- 上游流式回复中途断开、Claude Code 重新请求时，回复不再显示两遍。
- 重启后，对话窗格里打开的所有标签页都会恢复，不再只剩当前那个。
- .claude/commands 里的命令只由你来运行；模型只有在命令文件明确允许时才会自己调用。
- .claude/rules 里有无法读取的文件时跳过它，不再导致整个项目的规则都没加载。
- 命令输出卡片展开后，滚轮在卡片内滚动，并且有可拖动的滚动条。
- 从最近打开的项目或系统的打开请求打开 SSH 文件夹时能正常打开。
