New
- ACP subagent tasks use the same cards as Claude Code. Open a child conversation to inspect instructions, replies, reasoning and tool calls, including parallel and nested tasks.
- Support standard ACP subagent sessions, legacy Codex ACP session events and the Claude ACP transcript extension.

Improved
- Preserve child conversations through history replay, reconnects and subsequent rounds of work. Scope tool and message IDs to their sessions to prevent cross-talk.
- Keep parallel ACP command tasks, execution output and status available in the side panel.

Fixed
- Hide stop controls for ACP tasks that cannot be stopped independently.
- Null tool-update fields no longer erase previously reported input and output details.

Notes
- Full child conversations require the ACP backend to report child sessions or parent associations. Independent stopping of ACP subagents is not yet supported.
