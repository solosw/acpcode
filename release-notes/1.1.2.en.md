New
- ACP agents receive configured MCP tools when creating or restoring sessions, respecting user and project scopes, configuration precedence, and disabled servers.
- Support for stdio MCP, with HTTP and SSE enabled according to agent capabilities. Unsupported transports and invalid configurations show warnings in the conversation.

Improved
- SSH workspaces read MCP configuration, environment, and executable paths on the remote host, without mixing in Windows client paths.
- Restarting an ACP agent reloads MCP configuration and prevents stale startup work from replacing the new session's configuration.

Fixed
- Conversation file-change tracking after SSH reconnects: reopen the remote checkpoint store while preserving original snapshots, pending changes, and undo support.
- File-change scanning now starts when checkpoint initialization finishes during an active turn, so command-based edits can still appear in the conversation.
