新功能
- 从网站链接一键导入上游服务商；精选上游做成卡片，可以直接打开对方的站点。
- 模型选择器显示模型和上游的图标；每个模型的 effort 和上下文单独记住，切换时不再发一次测试请求。
- 对话里提到的文件可以直接用编辑器打开。
- 排队等待发送的消息停靠在输入框上方，可以编辑、立即发送或删除。
- 侧边栏「新建对话」下新增「打开项目」；资源管理器有前进/后退历史，侧边栏可以管理远程主机。
- 设置页面的列表能像侧边栏一样调整宽度、收起。
- MCP 服务器会显示是否可用，不响应时说明原因。
- macOS 上可以把文件从窗口拖到别的应用。

改进
- 命令面板和选择器：悬停只重绘两行，新增可点击的搜索行，边缘改为渐隐。
- 自动保存按 files.autoSave 设置执行，和 VS Code 一致。
- Windows 文字更清晰（像素对齐和引擎补丁）；OpenSSH 8.4 及以上会正常询问密码。
- 对话滚动条按比例缩放，阅读位置保持不变；悬浮提示会留在窗口内、避开边缘。

修复
- 停止对话后，未答复的调用和命令会失败返回，不再悬挂。
- 远程项目里展开文件变更、点开改动文件不再白屏或提示找不到文件（Windows）。
- 多文件夹工作区的变更审查卡住时，消息仍能正常发送。
- ACP 对话启动不再打断正在挂载的会话，切换会话时不会卡住。
