New
- Browse and install agents from the official ACP Registry on local and SSH hosts, with source, command and runtime details available before installation.
- Choose BaoCode network settings or the server network for SSH installations. Binary packages are selected for the remote operating system and architecture.

Improved

- Save agent commands, environment variables and customization directories per host to keep local and remote settings separate.
