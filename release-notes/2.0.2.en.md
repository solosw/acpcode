This release fixes file tracking in SSH ACP conversations and UTF-16 text being rejected as binary.

Fixed
- Wait for workspace snapshots before each ACP prompt, including the first message, queued messages and slash commands, so fast writes are not missed.
- Include successful ACP tool diffs in the conversation file list. Late subagent completions keep their original turn, and duplicate events after reconnect do not restore changes already kept.
- Preserve file hints outside the workspace across turn completion and conversation resume. Files without a reliable original are listed without Undo.
- Open BOM-marked UTF-16 LE/BE text in local and SSH editors, preserving its encoding, BOM and line endings when saved.
