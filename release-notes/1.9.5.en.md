This release adds an optional local model gateway that combines the models configured on your enabled upstreams into one local API.

New
- Enable the gateway in Settings → Models. The default address is http://127.0.0.1:8317 and the default API key is baocode; both can be changed.
- Connect clients using OpenAI Chat Completions, OpenAI Responses or Anthropic Messages, with streaming and supported cross-protocol conversation translation.
- Use BaoCode’s network proxy to reach upstreams, or choose a direct connection. Model IDs include the upstream ID to distinguish models with the same name.

Improved
- Preserve output token limits, supported sampling options and URL images when translating requests to Responses.
- Keep Anthropic model names unchanged when applying reasoning effort settings.
