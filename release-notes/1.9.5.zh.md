本次新增可选的本地模型网关，把所有已启用上游中配置的模型聚合到一个本地接口。

新功能
- 在“设置 → 模型”中开启网关。默认地址为 http://127.0.0.1:8317，默认密钥为 baocode，端口和密钥均可修改。
- 支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages，提供流式输出及受支持的跨协议对话转换。
- 可选择使用 BaoCode 网络代理访问上游，或直接连接。模型 ID 包含上游 ID，便于区分不同上游中的同名模型。

改进
- 转换到 Responses 协议时，保留输出 token 上限、受支持的采样参数和 URL 图片。
- 应用推理强度设置时保持 Anthropic 的真实模型名称不变。
