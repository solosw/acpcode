This release adds local model gateway calls to Usage, so calls from ACP agents and other clients can be tracked alongside Claude Code.

New
- Record gateway calls using OpenAI Chat Completions, OpenAI Responses and Anthropic Messages, including streaming and cross-protocol requests.
- Track upstreams, models, reported tokens, cache and reasoning usage, estimated costs, timing, errors and cancellations without counting translated requests twice.
- Identify clients with the x-baocode-agent header or a recognized agent User-Agent, and filter Usage by agent. Session and subagent headers preserve more detailed attribution.

Improved
- Show gateway sources and client names in call details and exported usage records. Older usage records remain readable.
- Request usage in OpenAI Chat Completions streams and read reported usage across split stream chunks. Missing token counts are not estimated.
