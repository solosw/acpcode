这一版为 ACP 接入系统提示词自定义与 Skills 支持，对接 BaoCode 内置内核提示词与本地/SSH Skills，并保持对现有 ACP v1 Agent 的兼容。

新功能
- 在 `session/new` 与 `session/load` 中接入 ACP `systemPrompt`（支持 `append` 与 `mode.override` 能力协商），自动同步「设置 → 内置内核」的系统提示词配置以及工作区/Bot 指令；Agent 不支持时安全跳过并给出提示。
- 支持 ACP v2 结构化 `skill` 命令项与 `skill` 提示词块（包含行内引用能力），面对 ACP v1 Agent 时自动兼容回退为纯文本。
- 自动加载本机与 SSH 远端 `~/.claude/skills` 和 `<project>/.claude/skills` 中启用的 BaoCode Skills（遵循「设置 → 自定义」开关与项目优先规则），支持向 `systemPrompt` 注入 Skills 目录、在 v1/v2 Agent 中通过 `/skill-name` 展开执行，并支持从命令标签直接打开 `SKILL.md`。
