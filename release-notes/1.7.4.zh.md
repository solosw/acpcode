上游合并与对话用量统计

新功能
- 在「设置 → 用量」和对话用量页查看调用次数、Token、模型价格和估算费用，包含 Claude Code 订阅调用。
- 使用 /btw 在当前对话旁提出独立问题，按 Esc 返回父对话，并可在侧栏折叠这些分支。
- 拖动消息队列调整发送顺序，并在项目分屏内通过标签管理对话。
- 配置 Codex 重置额度的使用方式，查看各账号的额度数量和过期提示。

改进
- 按每个对话独立记录文件编辑，优化 Git 提交详情和差异对齐。只有明确上报的文件编辑会归入对话；命令直接写入的文件不再通过全项目扫描自动发现。
- 保留本 fork 的 ACP Agent、定时任务、防止休眠和 GitHub 更新渠道，并将 SSH 审查重连、编辑时刻快照和撤销保护整合到新的审查机制中，避免覆盖用户后续修改。
- 降低智能体工作时的重绘频率，修复 iroh 端点监听空转问题。
