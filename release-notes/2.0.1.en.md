This release expands conversation coordination, adds Antigravity as a model provider, and improves SSH and browser tool reliability.

New
- Agents and bots can start conversations, choose their models, assign work in separate worktrees, and receive progress and completion reports.
- Fork a conversation from any completed turn. Suggested replies appear above the composer and come from the current response.
- Sign in with Google to use Antigravity models with the built-in core, including web search, image generation and per-model quotas. Customize the system prompt in Built-in Core settings.
- Pick which connected browser agents use and save files directly on the SSH host through the remote file picker.

Improved
- Search large projects in parallel, open files beyond the previous 50,000-file limit, and watch large remote directory trees with fewer stalls.
- Switch models across providers during a conversation. Turn costs reflect current usage prices, and mobile connections can fall back to another configured relay.

Fixed
- Keep the built-in MCP event stream alive while idle. The SSH relay reconnects after a temporary SSE disconnect without repeating tool calls.
- Respect custom subagent models across providers. Improve text selection, queued message dragging and model search with an input method.
