BaoCode 2.0.9 adds Antigravity CLI support and improves everyday agent workflows.

New
- Use Antigravity CLI through ACP, with its conversations, context, and usage available in BaoCode.
- See slash-command skills work as they run, and retry a stopped or failed last turn.
- Send images to agents as files, and open a terminal directly from the Files panel.
- Arrange conversations in up to four columns or two rows; queued messages survive quitting and reopening the app.
- Keep a new-chat draft when switching its project.

Improved
- Open files from the palette and terminal in the side panel; web-search steps show their source sites.
- Keep usage pages responsive with many subagents, and copy model-test errors more easily.
- Forward PDFs read by tools to OpenAI-compatible providers.

Fixed
- Keep scheduled-job conversations out of the visible process list; closing a window without a tray icon minimizes it.
- Keep the message editor visible in short windows and prevent code examples from breaking reply suggestions.
- Recognize Windows PowerShell Store aliases and handle Linux GL libraries and certificates with stray bytes.
