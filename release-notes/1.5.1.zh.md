新功能
- ACP Agent 可分别配置用户级 Skills 和 Rules 目标目录，预览并确认后复制到本机或所选 SSH 主机；Skills 包含完整资源，Rules 原样保留，不注入提示词。
- Git 账号新增 Gitea，可通过个人访问令牌登录 HTTP 或 HTTPS 实例，支持自定义 Web 端口、恢复登录和退出账号。
- Gitea 接入 Stash 核心功能：Issue 导入与同步、全部或我的议题筛选、发布、编辑、评论、关闭，以及 PR 状态、合并和可获取的检查／审查信息。

改进
- 自定义复制通过受管清单增量更新，保护既有及外部修改文件；源删除后保留目标并标记过期，同时检查目录重叠和链接路径。
- Gitea 按协议、主机和端口隔离账号及凭据，保留 HTTP 链接，并可将无歧义的 SSH remote 关联到已配置的 Web 实例。
- HTTP 登录前提示明文传输风险并要求确认；平台 API 不自动跟随重定向，避免把凭据发送到非预期地址。
- Gitea 暂不上传本地图片，发布前明确提示并阻止包含本地图片的发送；远程图片链接保持不变。

修复
- 仅修改 ACP Agent 的目录等设置时，保留原有带空格参数，避免保存时被错误拆分。
- 无权读取或不存在的 PR 检查和审查信息显示为未知，不再误判为通过。
- 平台返回非 JSON 内容时显示可处理的错误，保留会话与本地 Stash 数据。
