New
- Select models, operating modes and reasoning levels advertised by ACP agents, without hardcoded model or level lists.
- Adjust reasoning levels from the current model menu; agents that expose reasoning without a model selector get a standalone picker.

Improved
- Refresh dependent reasoning choices after model changes while retaining compatibility with the legacy ACP mode API.
- Apply configuration changes only after agent confirmation; rejected changes preserve the reported settings and leave the conversation usable.

Fixed
- Prevent older session setup or configuration responses from overwriting newer configuration notifications.
- Discard obsolete queued configuration changes when a session is restarted or closed.
