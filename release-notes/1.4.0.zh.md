新功能
- 新增 Linux 桌面支持，通过 GitHub Releases 提供 x64 和 arm64 安装包。
- 可在应用内新增和编辑 SSH 服务器，配置跳板机及每台服务器使用的内核，并保留原有主机登录设置。
- 用量限制重置后可自动继续会话，也可关闭自动继续。
- 显示实时回合统计，并在历史记录中保留回合耗时与费用。

改进
- 合入上游 Windows、Linux 浏览器集成，以及模型代理和子代理模型支持。
- 改善编辑器输入、触控板滚动、会话渲染和差异审阅体验。
- 保留本地 ACP 智能体、共享及无窗口 MCP 连接、修改审阅安全、自动保存行为和遥测控制。

修复
- SSH 连接与主机密钥配置检查统一使用已保存的用户、端口和密钥设置。
- 新增 Linux 下载入口的同时，保留手机端下载按钮与二维码。
