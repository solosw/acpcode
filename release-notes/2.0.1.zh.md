这一版扩展了对话协作，新增 Antigravity 模型上游，并改善了 SSH 和浏览器工具的连接稳定性。

新功能
- 普通对话 Agent 和 Bot 都能开新对话、指定模型、在独立 worktree 中派活，并接收进度和完成回报。
- 可从任意已完成的一轮分叉对话。推荐回复随当前回复生成，显示在输入框上方。
- 使用 Google 账号登录 Antigravity，通过内置内核使用其模型、网页搜索和生图，并查看各模型配额。「内置内核」设置支持自定义系统提示词。
- 可指定 Agent 使用哪个已连接的浏览器，也可通过远程文件窗口直接在 SSH 主机上另存文件。

改进
- 大项目文件搜索改为并行扫描，快速打开可找到超过原先 5 万文件限制的文件，远程大目录监听更流畅。
- 对话中可直接跨上游切换模型，每轮费用随用量价格更新。手机连接支持按顺序切换备用中继。

修复
- 内置 MCP 的 SSE 在空闲时会持续发送心跳。临时断线后，SSH 中继会重新订阅事件流，避免重复执行工具调用。
- 修复跨上游时子 Agent 的自定义模型选择，以及对话选区、排队消息拖动和模型搜索输入法问题。
