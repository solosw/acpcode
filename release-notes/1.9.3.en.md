This release brings in the upstream 2.0.0 series: BaoCode Bash on Windows, conversations that coordinate other conversations, additional project folders and settings migration, along with SSH terminal, file transfer and usage improvements.

New
- Windows can use BaoCode Bash with common commands included, without installing Git. Settings → General → Command Line also offers Git Bash, cmd, PowerShell and a custom program.
- Enable conversation coordination in Settings → General to let an agent assign work to other conversations, check progress and wait for results.
- Add folders to a project for agents, the file tree, terminals and @ mentions to use.
- Export settings, upstreams, models and shortcuts from Settings → Data Directory, then import them on another computer. API keys are included only when selected.
- When editing and resending an earlier message, choose whether to undo the agent's file changes from that message onward while keeping later changes from you or other conversations. Available for Claude Code and BaoCode Agent; command-made changes are excluded.
- Use code in an SSH terminal to open remote files and folders. Transfers show progress and can be cancelled, and the remote file browser can download folders.
- Manage project memories in Customize, connect GitCode accounts, and search Markdown and plan previews.
- View and use Claude subscription limit resets in model settings, and attach up to 100 images per message.

Improved
- Heavy terminal output no longer delays file and agent requests on the same SSH connection. Listing large conversations uses less memory.
- Conversations continued in an external terminal are reloaded automatically when returning to BaoCode.
- Third-party models use the context length reported by their upstream, with context usage aligned to the final request.
- Workflow shows subagent cards and progress, and archived conversations are grouped by folder.
- Linux .deb packages support glibc 2.31 systems, including Kylin V10 SP1 and UOS 20.
- With phone app 0.2.0, send files to agents, receive iPhone push notifications and reopen conversations faster.

Fixed
- Correct context counts for screenshots, tool results and interrupted streams, and cache-hit reporting when an upstream reports zero input tokens.
- Fix command and subagent permission decisions for third-party models in plan mode with full access, and image requests returning 400 on some Responses upstreams.
- Fix macOS window placement after external-display sleep and accessibility crashes, along with Windows Chinese input and proxy-variable compatibility.
- Improve chat text selection, WeChat voice input, Markdown formulas and skills installed through symbolic links.
- Fix remote file links, the SSH file browser and commit-panel interactions.
