Changelog

What changed in each version of BaoCode.

1.6.4

Fixed

  • Allow ordinary ACP tool permission requests by default. Local and SSH terminals no longer prompt for additional client approval, avoiding duplicate confirmations even when full access is selected.

Improved

  • Automatically select an allow option advertised by the agent while keeping actual command-selection menus interactive.
  • Retain terminal argument and working-directory validation, host and session isolation, output limits, and cancellation, disconnection and shutdown cleanup.

Notes

  • This changes ACP client approvals only. Permission options for the existing Claude Code channel and the ACP agent's own mode configuration are unchanged.

1.6.3

New

  • Support ACP V1 asynchronous terminals: start a command, continue the conversation, read output, wait for exit, and independently stop or release the terminal.
  • Available in local and SSH workspaces. Remote commands run in a PTY on the selected host and never fall back to this computer.

Improved

  • Integrate terminals with task cards and tool output, isolate main and child sessions, and retain displayed output after release.
  • Require approval for every command, showing the execution host, arguments, working directory and explicit environment variables. Recheck the directory before launch, bound captured output and filter terminal control sequences.
  • Handle cancellation races during approval and launch, and clean up client-owned terminals on disconnection and session shutdown. Never reuse an old approval after SSH reconnects to a new server.

Fixed

  • Hide ineffective stop controls for ordinary ACP tool tasks that cannot be stopped independently.
  • Preserve message ordering around terminal creation in both main and child conversations.

Notes

  • Requires an ACP backend using the standard terminal protocol. Codex-specific background-task extensions and survival after a lost connection are not included.

1.6.2

New

  • ACP subagent tasks use the same cards as Claude Code. Open a child conversation to inspect instructions, replies, reasoning and tool calls, including parallel and nested tasks.
  • Support standard ACP subagent sessions, legacy Codex ACP session events and the Claude ACP transcript extension.

Improved

  • Preserve child conversations through history replay, reconnects and subsequent rounds of work. Scope tool and message IDs to their sessions to prevent cross-talk.
  • Keep parallel ACP command tasks, execution output and status available in the side panel.

Fixed

  • Hide stop controls for ACP tasks that cannot be stopped independently.
  • Null tool-update fields no longer erase previously reported input and output details.

Notes

  • Full child conversations require the ACP backend to report child sessions or parent associations. Independent stopping of ACP subagents is not yet supported.

1.6.1

New

  • Preview PDF files directly in the editor and chat side panel, with page navigation and zoom controls.
  • Preview Word (.docx) documents with a lightweight native renderer, without installing Office or LibreOffice.
  • Preview Excel (.xlsx) workbooks as read-only tables, with worksheet switching and horizontal/vertical scrolling.
  • Compile local LaTeX source into a PDF preview using the bundled offline Tectonic engine, common packages and Chinese fonts. The preview uses unsaved editor content and preserves relative file references.

Fixed

  • Scrolling Word documents no longer unexpectedly zooms at the top or bottom; trackpad pinch zoom remains available.
  • Reloaded PDFs and recompiled LaTeX previews show the new output instead of a cached document.
  • PDF and Office files no longer pass through the text editor's UTF-8 reading or save paths.

Notes

  • Legacy .doc/.xls files must be saved as .docx/.xlsx. Advanced Office layout, Excel charts and formula recalculation are not supported.
  • LaTeX compilation is local only and uses a curated offline package set, not a full TeX Live installation. Missing packages produce a local error; no runtime downloads are performed. Compile only trusted LaTeX documents.

1.6.0

Fork updates (1.6.0+34)

  • Quick Run in the editor title bar supports multiple named startup commands, each with its own working directory. Select, add, edit or delete commands from the dropdown; each run opens a separate integrated terminal.
  • Run configurations and the selected command are saved per project and restored without automatically executing.
  • Includes upstream updates through 7510cc40, with expanded Git tools and improvements to file reviews, the side panel and SSH sessions.

Upstream release notes

Performance

This release is about speed and memory: in a long conversation, a reply streaming in, scrolling and dragging the minimap all keep up with you; the app holds much less memory as it runs; and on Windows the interface draws several times faster. Besides, Stash keeps in step with your projects' GitHub / GitLab issues, and an SSH connection that drops picks up the same session again, with nothing running there lost.

Performance

  • Windows draws with Skia, as macOS does, not Flutter's new default Impeller: measured, a frame of the chat takes a fraction of the time to draw, in about half the memory.
  • Long conversations stream more smoothly: each file path in a reply is no longer looked up in every file the session has read. On a real 92-turn conversation, a frame went from 6.8 ms to 4.5 ms, and janky frames from 18 to none.
  • Very long replies and thoughts let go of what is far out of view, keeping only its height, and show it again as it comes back; a thought draws only what is in view; code, tables and math scrolled sideways are kept as pictures. Select All and copying still get all of the text.
  • Dragging the minimap or the scrollbar fast no longer builds what is out of view meanwhile, catching up over a few frames after; a reply scrolled away and back is not parsed again. Dragged back and forth fast, a frame went from 12.9 ms to 2.5 ms.
  • Less memory: Skia's texture cache is held to 32 MB rather than 150 to 300 MB, and decoded images to 48 MB; on macOS large blocks freed go back to the system, some 180 MB while a long thought streams.
  • Leaner editors: files of the same language share one syntax highlighting worker, its patterns compiled once (TypeScript's 334 were compiled in some 3,500 places), and line layouts are held to about 32 MB.
  • In plan mode the prompt cache is read again: each turn wrote the whole conversation to it anew, slower and dearer.
  • A trackpad flings the editors on as it does lists; on macOS lists no longer bounce at their ends.

New

  • Stash and issues, both ways: in a project that is a GitHub / GitLab repository, open issues become stashes, one row each with its status, title, conversation and issue. Kept in step: changed there, taken here; changed here, pushed once you confirm; changed on both sides, yours to pick; an issue closed, its stash is done. Every open issue by default; Settings → Stash → Issues as stashes keeps it to yours, or off.
  • Stash news: new comments on an issue, one closed or reopened, a linked pull request's checks failing, changes asked for, merged: each marked on its row, and those about you counted beside Stash in the sidebar. A pull request failing or asked for changes is fixed in its conversation in a click; a merged one asks whether the stash is done.
  • A stash can be published as an issue: what goes is shown first, local paths and secrets pointed out, local pictures uploaded with it. Merging stashes can close a merged one's issue as a duplicate.
  • A new markdown editor: stashes, markdown previews in the side panel and the chat's input are edited as they read, the marks showing only where the caret is. Tables are edited in their cells: rows and columns added and removed, cells picked, copied and pasted as in a spreadsheet; a link shows a bubble to open, copy, edit or remove it.
  • Customize: skills, rules, commands and subagents open in the markdown editor, edited as they read or as their source; front matter shows as properties, edited as a form.
  • SSH drops lose nothing: after a network hiccup the connection goes back to the same session, its terminals, Claude Code and language servers still running there (kept up to three hours while disconnected), no output lost or repeated; a silent network is noticed within 30 seconds.
  • Going on after the usage limit: on Claude's own account, the model picker has Continue After Limit Reset. On, a conversation stopped at the limit goes on once it resets, even with the computer asleep past it; one due while the app was closed goes on as it opens.
  • The Claude Code CLI, recommended: where Claude Code is installed it is the core by default; a conversation on the built-in core suggests switching, above its input, downloading the CLI in a click, or Not Now.
  • Models: subagents and the Opus / Sonnet / Haiku tiers can use another upstream's models; a model can have its own endpoint (Anthropic, Chat Completions, Responses); an upstream or a model is duplicated in a click; models an upstream no longer lists are removed at once.
  • The minimap: each of your messages is a clear mark on it. The pointer near one snaps to it and shows at once the message and the replies around it; a click goes there.
  • The input: a / starting any word opens the command menu; a command's tag shows its whole description on hover, and Open details opens its file in the side panel. @ finds folders too. File, folder and code chips in the input open what they name.
  • While the agent works, Enter in the empty input sends the first queued message now; background tasks (subagents among them) keep going.
  • A changed file's right click opens it in the browser (HTML), its default app or another editor, shows it in the file manager, or copies its path.
  • The side panel's markdown preview takes pictures and files dropped or pasted in, copied beside the document and linked; a right click shows a link's file in the file manager.

Fixed

  • A conversation switched away from and back to is where you left it, its steps still open.
  • A conversation renamed in Claude Code (/rename) is renamed in the list.
  • With "viewMode": "verbose" in Claude's settings, Stash's polish, the input's polish and commit messages no longer fail.
  • A single ~ (a range such as 10-12~10-16) no longer strikes text out.
  • The markdown preview fills the view, wide tables no longer cut off; zoomed in, a drag in it selects under the pointer.
  • With the side panel at the left and the sidebar hidden, its tabs keep clear of the traffic lights on macOS, and the sidebar's toggle is there too; dragging its edge follows the pointer from the width shown.
  • Go to Definition in a remote project opens the right file on its host.
  • Windows: updating or uninstalling ends the browser extension's host first, no longer failing with "DeleteFile failed; code 5".

1.5.5

Improved

  • ACP tasks keep running when you leave a conversation. Idle sessions without an open view release their process, including after background work completes.
  • Reopening an ACP conversation restores its original session without appending duplicate history. Unsupported restoration now reports an error instead of silently creating a new session.
  • Closing ACP waits for local or remote process exit and escalates termination on timeout. App exit also waits for sessions that are still shutting down.

Fixed

  • Raised the macOS app file-descriptor soft limit and coalesced concurrent keychain reads for the same account to reduce resource exhaustion.
  • Fixed races between MCP SSE writes, heartbeats and connection closure that could cause repeated errors.
  • Preserved existing file changes when scans encounter temporary descriptor exhaustion, and blocked unsafe undo when a reliable baseline cannot be captured.

1.2.0

Meet Stash

A big release. Stash is new: jot down ideas, screenshots and links from any app, hand them to an agent when they're ready, and see how each one is going at a glance; sign in to GitHub or GitLab to import issues into it and keep issues and pull requests up to date. The phone app's beta is now on the download page. Git, the Fast IDE, remote hosts and model settings gain a good deal more, and a long list of problems is fixed.

New

  • Stash: an inbox for whatever comes to mind. Set a global shortcut in Settings → Stash and press it in any app to bring up a floating panel and note something down (none is set by default, so as not to clash with other apps). Text, screenshots, files, links, code, tables and formulas all go in, and each note has its own number, like an issue.
  • Keeping Stash tidy: pin notes, drag them into order, filter by time, project and status, and merge duplicates; search finds text inside images too, and AI search finds notes by meaning.
  • Handing a note to an agent: click Implement in BaoCode and choose a new git worktree or the current branch, or @ the note in a chat. The chat and the note are linked, and the note's card shows how the chat is going.
  • AI to say it clearly: Polish smooths the selected text, and Clarify turns a one-liner into a full request, using its images and attachments; both can be undone.
  • Accounts (Settings → Accounts): sign in to GitHub or GitLab, in the browser or with a token, GitHub Enterprise and self-hosted GitLab included. Issues and pull requests linked from Stash show their latest state and checks; import issues from your projects' repositories, and reply to or close an issue once you've confirmed, with a warning first if the text looks like it holds a local path or a secret. Tokens are kept only in this computer's keychain.
  • The phone app (beta): download it for Android or iOS from the download page, pair it with your computer, and follow and steer its agents from your phone.
  • Phones through a Cloudflare Tunnel: write the public address in Settings → Mobile as wss://your-domain, and leave the domain's Always Use HTTPS on.
  • Branch bar: the current Git branch over the chat, to search, switch and create branches; a workspace of several folders lists each folder's branch. Switching waits while an agent runs, so as not to pull the ground from under it.
  • In plan mode, the plan's card has a Start button: leave plan mode and get going on the plan in one click.
  • Each chat picks its own model; Codex's Fast tier has moved there, and both Responses and Codex upstreams support Fast.
  • Find in Chat (⌘F / Ctrl+F), and Paste as Plain Text (⇧⌘V / Ctrl+Shift+V).
  • Settings → Appearance → Interface Size scales text, icons and spacing together; the terminal's text follows it, or takes a size of its own.
  • Settings → Customize: create, edit and delete project and global rules, skills, subagents, commands, MCP servers, hooks and plugins right in the settings.
  • Custom request headers for each upstream in the model settings, with the session ID and model name available as variables.
  • Git: fetch, pull and push; pick the repository in a project with several, with submodules as repositories of their own; the graph can show every branch, names each commit's branches and tags, and lists a commit's files as a tree.
  • Files: search the whole project's text from the side panel; open a file link from a chat in the side panel, preview it or open it in the browser; Open in Terminal in the explorer, and choose which files and folders it hides in the settings.
  • Fast IDE: turn on Show agent changes as diffs to have each file an agent changes open as a diff as it goes; change a file's language mode by hand; format JSON and other files without a language server.
  • Remote hosts: the host indicator in the status bar has a menu, and files on a remote host open directly over SSH, with the ones opened lately listed.

Improved

  • The sidebar's agent list is rebuilt, with multi-selection to pin, archive and delete several at once; archived agents can show in the IDE too.
  • The Fast IDE opens in the main window by default, in place of the chat; switch back to a window per folder in the settings.
  • An earlier conversation shows that it's loading while it opens, and very long conversations run more smoothly.
  • The subagents and background tasks running show over the composer, a click away.
  • Quick Open in a remote project waits on neither the connection nor the ranking.

Fixed

  • A queued message taken back to edit lands in the composer instead of being lost, and one sent now ahead of the rest is no longer lost either.
  • A project folder that has been deleted or moved is reported in the app's language.
  • The model providers' keys come along when the data folder moves.
  • Claude Code's own models are always listed, and kept between runs.
  • A key the base URL refuses is reported, rather than left as an empty list.
  • The window buttons' place, the editor's icons, trackpad scrolling, and list selection and highlighting match the IDE's in many small ways.
  • And a batch of smaller fixes: text typed into a URL jumping about, the model's name cut short in a narrow composer, saves of one Stash note overwriting each other, and more.

1.0.0

The first release of BaoCode: a desktop app for Claude Code, with a fast IDE built in. For macOS (Apple silicon and Intel) and Windows.

Chat

  • Steps fold into single lines, and the current task and its progress stay above the input
  • Review what Claude changed, file by file, and keep or undo it; checkpoints never touch your repository’s .git
  • Give Claude a goal with /goal, and it keeps working until the goal is met
  • A rich-text input: paste images, drop in files, and copy code from the editor as a reference to its lines
  • Edit a message you sent, search your conversations, and see your context and plan usage
  • Run several agents side by side, in tabs or in windows of their own
  • Choose how the commits and pull requests Claude writes are credited

SSH remote projects

  • Open a folder on a Linux host over SSH, as with VS Code’s Remote-SSH: the window stays on your machine, and files, search, Git, terminals, language servers and Claude Code run on the host
  • Pick a host from ~/.ssh/config, or type user@host
  • Claude Code is installed on a host that has none, and your models work there too
  • Reconnects by itself; when a host can’t be reached, you’re told why and can retry

Fast IDE

  • An editor, a terminal and Source Control with a commit graph and Git blame
  • Your VS Code themes, keybindings and language servers
  • Markdown files open as a preview you can edit in place, Typora’s way
  • Commit messages drafted by Claude Code, for you to edit and commit

Models and extensions

  • Use other models through Claude Code: Anthropic’s API, OpenAI’s Chat Completions or Responses, with API keys kept in the system keychain
  • Choose the model for each part of Claude Code’s work, and for titles and commit messages
  • Plugins, MCP servers, skills, subagents, rules, commands and hooks in one place, with your skills from claude.ai

Around the app

  • Notifications, a sound and a count on the app’s icon when an agent needs you; agents keep running in the menu bar or tray when the window is closed
  • Open a folder in BaoCode from Finder or Explorer, and keep a window on top of others
  • In English and Chinese
  • Updates itself in the background, and asks before restarting
