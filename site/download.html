The same extension as a zip, for a browser that can’t reach the store, or to get a version before the store has it. It doesn’t update itself: download it again for a new version.

Download zip

Lets BaoCode’s agents use your own browser, signed in as you are: open pages, read them, click and type, while you watch them do it in the side panel. They only see the tabs you share with them, those in the yellow BaoCode tab group; your other tabs stay yours. Everything stays on your computer. macOS for now; Windows is coming. Privacy.

To load the zip in developer mode: unzip it into a folder you’ll keep (the browser loads it from there each time), open chrome://extensions, turn on Developer mode in the top right, click Load unpacked and choose the folder. For a new version, unzip it over the old one and click the reload arrow on the extension’s card.

Then, in BaoCode, open Settings → Browser to check it’s connected.

Before you start

BaoCode runs Claude Code; it doesn’t replace it. Install Claude Code first, then open a folder in BaoCode and start a chat.

Not sure which Mac you have? Choose About This Mac in the Apple menu: a Chip line means Apple silicon, a Processor line means Intel.

On a Mac, drag BaoCode into Applications. It isn’t notarised by Apple yet, so the first time you open it macOS stops it: open System Settings, then Privacy & Security, and click Open Anyway beside BaoCode. Only the first time.

Updating

BaoCode updates itself in the background and asks before restarting. If it sent you here, it couldn’t update itself: download the new version above and install it over the old one. Your settings and conversations are kept.
