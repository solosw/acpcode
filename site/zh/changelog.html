BaoCode 每个版本的变化。

1.6.0

性能优化

这一版主要在提速和省内存：长对话里回复流式输出、滚动、拖动缩略图都更跟手，长时间运行占用的内存明显变少，Windows 上画面绘制快了好几倍。另外，Stash 现在能和项目在 GitHub / GitLab 上的 issue 双向同步；SSH 断线后会自动接回原来的会话，远程正在跑的东西一样不丢。

性能

  • Windows 改用 Skia 绘制界面（和 macOS 一样），不再用 Flutter 新默认的 Impeller：实测对话界面每帧的绘制时间只有原来的几分之一，内存也只占原来的一半左右。
  • 长对话流式输出更流畅：回复里的每个文件路径，不再到会话读过的所有文件里逐个去查。在一段 92 轮的真实对话里，每帧耗时从 6.8ms 降到 4.5ms，卡顿帧从 18 个降到 0。
  • 很长的回复和思考过程，离屏幕很远的部分会先释放、只占住高度，滚回来再显示；思考过程只绘制看得见的部分；横向滚动的代码、表格和公式会缓存成图片。全选和复制照样能拿到全部文字。
  • 快速拖动对话缩略图或滚动条时，不再提前构建看不见的内容，松手后再分几帧补上；滚出去又滚回来的回复不用重新解析。来回快速拖动时，每帧耗时从 12.9ms 降到 2.5ms。
  • 更省内存：Skia 留着的纹理缓存从 150～300MB 降到 32MB，图片缓存限制在 48MB；macOS 上释放掉的大块内存会还给系统，长思考流式输出时少占约 180MB。
  • 编辑器更省：同一种语言的文件共用一个语法高亮进程，规则只编译一次（以前 TypeScript 的 334 条规则要在约 3500 个地方各编译一遍）；行排版缓存限制在 32MB 左右。
  • 计划模式下提示词缓存能正常命中了：以前每一轮都要把整个对话重新写进缓存，又慢又费钱。
  • 触控板在编辑器里滑动松手后也有惯性，和列表一致；macOS 上列表滚到头不再回弹。

新功能

  • Stash 与 issue 双向同步：项目是 GitHub / GitLab 仓库时，打开的 issue 会自动成为 Stash，一条一行，状态、标题、关联的对话和 issue 一目了然。两边的修改保持一致：那边改的直接拿过来，这边改的确认后才推上去，两边都改了由你来选；issue 关闭，Stash 也随之完成。默认同步全部打开的 issue，可以在设置 → Stash 的「Issue 同步为 Stash」里改成只同步我的，或者关闭。
  • Stash 动态：issue 有新评论、被关闭或重新打开，关联的 PR 检查失败、被要求修改、已合并，都会在行上标出来，和你有关的计入侧栏 Stash 旁的数字。检查失败或要求修改的 PR 可以一键回到它的对话里去修，已合并的会问你这条 Stash 是否完成。
  • Stash 可以发布成 issue：发布前列出要发出去的内容，并提醒其中的本地路径和密钥，本地图片会一起上传。合并 Stash 时，被合并的那条 issue 可以作为重复关闭。
  • 新的 Markdown 编辑器：Stash、侧边栏里的 Markdown 预览和对话输入框，都改成所见即所得地编辑，标记只在光标所在的地方显示。表格直接在单元格里编辑，能增删行列，像电子表格一样框选、复制、粘贴；链接上会弹出气泡，可以打开、复制、编辑或移除。
  • 自定义：技能、规则、命令和子代理的 .md 文件用 Markdown 编辑器打开，可以直接编辑，也可以切到源码；文件开头的 front matter 显示成属性，像填表一样修改。
  • SSH 断线不丢工作：网络闪断后会自动重连到原来的会话，远程的终端、Claude Code 和语言服务器都继续运行（断开期间最长保留 3 小时），中间的输出不丢也不重复；网络断了 30 秒内就能发现。
  • 达到用量限额后自动继续：用 Claude 自己的账号时，模型选择器里有「限额重置后自动继续」开关。打开后，因限额停下的对话会在重置后自动接着做，电脑睡过了重置时间也一样；应用关着时到点的，下次打开时继续。
  • 推荐使用 Claude Code CLI：本机装了 Claude Code 的，默认就用 CLI；还在用内置内核的对话，输入框上方会建议切换，点一下就自动下载并切过去，不想换就点「暂不」。
  • 模型：子代理和 Opus / Sonnet / Haiku 三档可以选用别的上游的模型；每个模型可以单独指定接口（Anthropic、Chat Completions、Responses）；上游和模型都能一键复制；上游已经下架的模型可以一次移除。
  • 对话缩略图：你发的每条消息在缩略图上都是一个醒目的标记。鼠标靠近会自动吸附，立刻弹出这条消息和前后回复的预览，点一下就跳过去。
  • 输入框：任何一个词的开头输入 / 都能打开命令菜单；悬停在命令标签上能看到完整说明，「查看详情」会在侧边栏打开它的文件。@ 也能搜到文件夹。输入框里的文件、文件夹和代码片段标签都能点开。
  • 智能体工作时，在空输入框里按回车会立即发送排队的第一条消息；后台任务（比如子代理）正在跑的话，不会被打断。
  • 右键改动过的文件：可以在浏览器（HTML 文件）、默认应用或别的编辑器里打开，在文件管理器里显示，或者复制路径。
  • 侧边栏的 Markdown 预览里可以拖入或粘贴图片和文件，会复制到文档旁边并插入链接；右键可以在文件管理器里显示链接指向的文件。

修复

  • 切到别的对话再切回来，会回到原来看到的位置，展开的步骤也还展开着。
  • 在 Claude Code 里用 /rename 改的对话名会同步到列表。
  • Claude 设置里开了 "viewMode": "verbose" 时，Stash 的润色、输入框的润色和生成提交信息不再失败。
  • 单个 （比如 10-1210-16 这样的范围）不再被当成删除线。
  • Markdown 预览铺满整个视图，宽表格不再被截断；界面缩放后，在预览里拖选文字会选在鼠标所在的位置。
  • 侧边栏放在左边且隐藏侧栏时，标签页会避开 macOS 左上角的红绿灯，显示侧栏的按钮也挪到了这里；拖动侧边栏边缘时从当前宽度开始跟手。
  • 远程项目里跳转到定义，会在远程主机上打开正确的文件。
  • Windows：升级或卸载时会先关掉浏览器扩展的后台程序，不再报「DeleteFile failed; code 5」。

1.5.0

新功能

  • Stash 可与 GitHub / GitLab 的 issue 双向同步，展示评论、状态和关联 PR 动态，支持确认后发布及合并议题。
  • Stash、Markdown 预览和对话输入框采用新的 Markdown 编辑器，支持表格单元格编辑、链接操作和 front matter 属性编辑。
  • SSH 网络中断后可重新接回原会话，保留远程终端、智能体和语言服务器，并补齐断线期间的输出。
  • 模型支持跨上游的角色配置、独立接口、一键复制及移除已下架模型；对话缩略图新增用户消息定位与预览。

改进

  • 减少长对话、语法高亮、图片和排版缓存的内存占用，改善流式输出和快速滚动；Windows 改用 Skia 绘制。
  • 输入框支持打开文件及文件夹标签、查看命令详情，并在智能体工作时快速发送排队消息。
  • 保留本地 ACP 模型、模式和思考等级选择、共享及无窗口 MCP、修改审阅、SSH 保存配置和 GitHub 更新渠道。

修复

  • 修复 Markdown 图片加载导致滚动位置跳动、表格链接操作及部分 Windows 输入问题。
  • 修复 Claude Code 思考等级受环境变量锁定、会话重命名不同步和计划模式提示词缓存问题。
  • 修复工具栏缓存导致仅提供思考等级的 ACP 智能体选择器未及时刷新的问题。

1.3.2

浏览器工具连接更稳定

改进

  • 支持 HTTP 的本地 ACP Agent 共用应用内的 MCP 服务，不再为每个对话额外启动一个 BaoCode 转发进程。每个对话保留独立的项目上下文和访问凭据，取消操作互不干扰。
  • 用户级 MCP 注册继续支持外部客户端与仅支持 stdio 的 Agent；用户自定义同名服务器、项目覆盖、禁用设置和 SSH 远端配置保持原样。

修复

  • macOS 的 MCP 标准输入输出转发进程不再创建应用窗口或抢占焦点。
  • 对话关闭、Agent 退出或重启时释放共享 MCP 连接，撤销临时凭据并取消未完成的调用。

1.3.1

浏览器工具，每个 agent 都能用

修复版本：内置工具现在也能给应用之外的 agent 使用，对话重新追踪本地 agent 的文件改动，编辑器边写边保存。

新功能

  • 内置工具共享：浏览器的工具和图片生成注册为「用户级」MCP 服务器，因此在应用旁边运行的 agent（如 ACP agent）也能拿到 Claude Code 用的同一套工具。它们只操作用户共享出来的标签页，且只在这台机器上：远程主机仍然只读取它自己的配置。

修复

  • 自动保存默认开启：停止输入后即写入，和 VS Code 一样。可以在设置里关掉，或换成别的模式。
  • 本地 agent 的文件改动重新可以追踪：它通过 shell 改过的文件会像 SSH 时一样出现在对话里，可以保留或撤销。审查打开之前到达的改动也不会丢；保留或撤销都不会覆盖你自己的修改。
  • 变更审查打开期间，对话不再被卡住。

1.2.0

Stash 来了

这是一次大更新。新增 Stash：在任何应用里随手记下想法、截图和链接，准备好了一键交给 agent 去做，每条的进展一眼看清；登录 GitHub 或 GitLab 后，还能把 issue 导入 Stash，并同步 issue 和 PR 的状态。手机版 Beta 也可以在官网下载了。此外，Git、Fast IDE、远程主机和模型设置都有不少增强，并修复了一大批问题。

新功能

  • Stash：随手记的收件箱。在 设置 → Stash 里设一个全局快捷键，在任何应用里按下就会弹出浮动面板记一条（默认不设，避免和其他应用冲突）。文字、截图、文件、链接、代码、表格、公式都能放进去，每条都有自己的编号，像 issue 一样。
  • 整理 Stash：可以置顶、拖动排序，按时间、项目、状态筛选，合并重复的便签；搜索时连图片里的文字也能搜到，也可以用 AI 按意思搜索。
  • 交给 agent：点「在 BaoCode 中实施」，选择在新的 git worktree 里开发，还是直接在当前分支上开发；也可以在对话里 @ 一条 Stash。对话和便签会自动关联，卡片上实时显示对话的状态。
  • AI 帮你写清楚：「润色」把选中的文字理顺，「说清楚」结合图片和附件把一句话补全成完整的需求，都可以撤销。
  • 账号（设置 → 账号）：用浏览器或令牌登录 GitHub、GitLab，也支持 GitHub Enterprise 和自建 GitLab。Stash 里链接的 issue 和 PR 会显示最新状态和检查结果；可以从项目的仓库导入 issue，并在你确认后回帖、关闭 issue，发出前会提醒内容里是否带有本机路径或密钥。令牌只保存在本机钥匙串里。
  • 手机版 Beta：Android 和 iOS 版可以在官网下载页下载，和电脑配对后，在手机上查看并操作电脑上的智能体。
  • 经 Cloudflare Tunnel 连手机：设置 → 手机 的公网地址可以写成 wss://域名，不必再为此关闭域名的「始终使用 HTTPS」。
  • 分支栏：对话上方显示当前 Git 分支，可以搜索、切换和新建分支；多文件夹的工作区会分别列出各文件夹的分支。agent 运行时不能切换，以免打乱它的工作。
  • 计划模式下，计划卡片上多了「开始执行」按钮，一键退出计划模式、按计划开始。
  • 每个对话可以单独切换模型；Codex 的 Fast 档也移到了这里，Responses 和 Codex 上游都支持 Fast。
  • 在对话中查找（⌘F / Ctrl+F），以及粘贴为纯文本（⇧⌘V / Ctrl+Shift+V）。
  • 设置 → 外观 → 界面大小：整体缩放文字、图标和间距；终端字号可以跟随界面大小，也可以单独设定。
  • 设置 → 自定义：项目和全局的规则、技能、子智能体、命令、MCP 服务器、钩子和插件，都能直接在设置里新建、编辑和删除。
  • 模型设置里可以给每个上游加自定义请求头，值里可以用会话 ID 和模型名变量。
  • Git：获取、拉取、推送；多仓库的项目可以选择仓库，子模块作为独立的仓库显示；提交图可以显示所有分支，标出每个提交所在的分支和标签，提交里的文件以目录树显示。
  • 文件：侧边栏可以搜索整个项目的文本；对话里的文件链接可以在侧边栏打开、预览，或在浏览器中打开；资源管理器可以「在终端中打开」，隐藏哪些文件和文件夹也可以在设置里配置。
  • Fast IDE：可以打开「以 Diff 显示智能体改动」，agent 每改一个文件就以 Diff 打开，随改随看；可以手动更改文件的语言模式；没有语言服务器时也能格式化 JSON 等文件。
  • 远程主机：状态栏的主机指示器有了菜单，可以经 SSH 直接打开远程主机上的文件，并列出最近打开过的远程文件。

改进

  • 侧边栏的智能体列表重做，支持多选，可以批量置顶、归档和删除；已归档的智能体在 IDE 里也能显示。
  • Fast IDE 默认在主窗口中打开，替换对话；想要每个文件夹一个独立窗口，可以在设置里改回来。
  • 打开较早的对话时会显示加载状态；很长的对话也更流畅了。
  • 输入框上方会显示正在运行的子代理和后台任务数量，点一下就能打开。
  • 远程项目里的快速打开不再等连接和排序，打开更快。

修复

  • 排队中的消息点「撤回并编辑」后会回到输入框，不再丢失；用「中断当前任务，立即发送」插队的消息也不会再丢。
  • 项目文件夹被删除或移走时，会用应用的语言给出提示。
  • 数据文件夹搬家时，模型服务商的密钥会一起带过去。
  • Claude Code 自带的模型总会列出，重启后也会保留。
  • 密钥被 Base URL 拒绝时会明确提示，而不是只显示一个空列表。
  • 窗口按钮的位置、编辑器图标、触控板滚动、列表的选择和高亮等多处细节，和 IDE 保持一致。
  • 还修了一批小问题，比如在网址里输入的文字跳位置、窄输入框里模型名被截断、同一条 Stash 连续保存时互相覆盖等。

对话

  • 执行步骤折叠成一行，当前任务和进度固定显示在输入框上方
  • 按文件查看 Claude 做的修改，逐个保留或撤销；检查点不会碰你仓库的 .git
  • 用 /goal 给 Claude 设定目标，它会一直工作到目标达成
  • 富文本输入框：粘贴图片、拖入文件，从编辑器复制的代码会变成对文件和行号的引用
  • 可以编辑已发送的消息、搜索历史对话，查看上下文和套餐用量
  • 多个智能体并排运行，可以放在标签页里，也可以各开一个窗口
  • 可以设置 Claude 写的提交和 Pull Request 里的署名

SSH 远程项目

  • 通过 SSH 打开 Linux 主机上的文件夹，体验和 VS Code 的 Remote-SSH 一样：窗口留在本机，文件、搜索、Git、终端、语言服务器和 Claude Code 都在远端运行
  • 从 ~/.ssh/config 里选主机，或者直接输入 user@host
  • 远端没有 Claude Code 时会自动安装，本机配置的模型在远端也能用
  • 断线自动重连；连不上时会说明原因，可以一键重试

Fast IDE

  • 编辑器、终端，以及带提交图和 Git 追溯（blame）的源代码管理
  • 沿用你的 VS Code 主题、快捷键和语言服务器
  • Markdown 文件以预览方式打开，可以像 Typora 一样直接在预览里编辑
  • 提交信息由 Claude Code 起草，你修改后提交

模型与扩展

  • 通过 Claude Code 使用其他模型：支持 Anthropic API、OpenAI Chat Completions 和 Responses，API 密钥保存在系统钥匙串里
  • 可以为 Claude Code 的各类工作分别选择模型，标题和提交信息也可以单独选
  • 插件、MCP 服务器、技能、子代理、规则、命令和钩子集中管理，claude.ai 上的技能也会同步过来

  • 可以从访达或资源管理器直接用 BaoCode 打开文件夹，窗口也可以置顶
